**ClinicFlow**



AI-powered WhatsApp automation and clinic management platform
ClinicFlow helps small and medium-sized clinics in Pakistan automate routine patient communication through WhatsApp while giving clinic owners a simple dashboard to manage clinic information, appointments, patients, and basic financial records.
The clinic owner does not need to manually program these responses. They configure the clinic through the dashboard, and the WhatsApp assistant uses that information dynamically.

**Problem**



Many local clinics receive repetitive WhatsApp messages such as:
•	Is the clinic open today?
•	Doctor kab bethte hain?
•	Consultation fee kitni hai?
•	Location send kar dein.
•	Appointment leni hai.
•	Which doctors are available?
•	What services do you provide?
Staff must repeatedly answer these questions and manually record patient information.
This creates:
•	Wasted staff time.
•	Inconsistent responses.
•	Missed inquiries.
•	Poor record keeping.
•	Limited visibility for clinic owners
